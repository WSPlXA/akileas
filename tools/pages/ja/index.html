ネイティブ性能 · ローカルファースト · 目に優しい配色

思考のスピードに
遅れをとらない。

ホメロスの「駿足のアキレウス」にその名を由来する Akileas は、妥協のない応答速度と深い集中のために設計されています。Markdown の記法はカーソルの位置で滑らかに展開し、カーソルが離れた瞬間に端正なタイポグラフィへと収まります。左右分割のわずらわしさも入力の遅延もありません。ただ、純粋な流れのままに書くだけです。

設計思想

駿足のアキレウス

ホメロスの『イリアス』において、英雄アキレウスは「駿足」（πόδας ὠκὺς Ἀχιλλεύς）と讃えられています。そこには鋭敏な機動力、妨げられることのない勢い、そして純粋な速さが宿っています。書き物の道具が重い Web ランタイムや鈍重な Electron ラッパーに押し潰されていた時代に、Akileas はその軽やかな速さを取り戻します。押した瞬間に反応するキー入力、静かな簡潔さ、そしてあなたの邪魔をしないキャンバスです。

σευάμενος ὥς θ᾽ ἵππος ἀεθλοφόρος σὺν ὄχεσφιν,
ὅς ῥά τε ῥεῖα θέῃσι τιταινόμενος πεδίοιο·
ὣς Ἀχιλεὺς λαιψηρὰ πόδας καὶ γούνατ᾽ ἐνώμα.

「褒賞を勝ち取った駿馬が戦車を引き、平原を軽やかに全力で駆け抜けるように、
アキレウスもまた、しなやかな足と膝をすばやく運んだ。」

—— ホメロス『イリアス』第 22 巻（22–24 行）

連続するインタラクティブキャンバス

書いたものが、そのまま読める。

Markdown の記法はカーソルのある行にだけ姿を現し、カーソルが離れた瞬間に洗練されたタイポグラフィへと収まります。画面を左右に分ける必要も、頭の中で切り替える必要もありません。ひとつの画面の上で、執筆と読書をシームレスにつなぎます。

主要機能

集中のために設計し、精密さに根ざす

思考の下に消えてしまうほど軽く、複雑な技術原稿にも十分に応える。

I

その場で完結するハイブリッド WYSIWYG

左右に分かれたプレビュー画面はもう必要ありません。生の Markdown 記法が展開するのは、カーソルのある行だけです。見出し、リスト、テーブル、リンク、太字はリアルタイムでインライン表示され、キャンバスは常に端正に保たれます。

## 没入できる執筆フロー カーソルが先へ進むと、テキストは滑らかに出版品質のレイアウトへと収まります。

II

GitHub アラートのコールアウト

標準的な GFM アラート記法に完全対応：[!NOTE]、[!TIP]、[!IMPORTANT]、[!WARNING]、[!CAUTION]。編集中は記法が展開し、カーソルが先へ進むと、柔らかなアクセントの付いた洗練されたコールアウトカードへと折りたたまれます。

TIP · コールアウトブロック

カーソルが行を離れた瞬間、記法は静かでエレガントなカードへと折りたたまれます。

III

スマートなテーブル移動 & 整列

Markdown の列揃え記法に完全対応（:--- は左寄せ、:---: は中央、---: は右寄せ）。Tab と Shift-Tab でセル間を軽やかに移動でき、最後のセルで Tab を押すと新しい行が自動的に追加されます。

IV

ネイティブな数式 & 図表レンダリング

TeX/LaTeX の数式、Mermaid のフローチャートとシーケンス図、シンタックスハイライト付きのコードフェンス、タスクリストを第一級の機能としてサポートします。ブラウザランタイムや重量級のスクリプトエンジンを一切使わず、GPU がネイティブに描画します。

E = mc²

V

内蔵タイムマシン & 自動復旧

保存のたびに最大 100 件の軽量スナップショットを自動で記録し、オフラインでの差分確認とワンクリックでの巻き戻しに対応します。容量を抑えたバイナリ復旧ログに支えられ、未保存の作業は予期しないクラッシュや停電を生き延びます。

本気の執筆のための、細やかな配慮

繊細なタイポグラフィのアクセントから、数千語に及ぶエンジニアリング文書まで、あらゆる操作を丁寧に磨き上げています。

相対ローカルパスとリモートのネットワーク URL に対応し、幅を明示する属性（例：<img width="400">）も使えます。専用のワーカースレッドが画像を GPU テクスチャへデコードするため、画像の多い原稿でもスクロールが引っかかりません。

低遅延ファーストのアーキテクチャ

UI スレッドは決して待たない。

遅延は妥協のない不変条件として扱われます。キー入力はひとつの軽量な編集として適用され、影響を受けた行の暫定的な表示が即座に再描画されます。そのうえで、完全な再解析、レイアウト計算、永続化がバックグラウンドで非同期に収束していきます。

高速トラック · 体感される部分（1 ms 未満） 入力から描画まで：ブロックも待ちも、無駄な処理もなし

→
II バージョンを付与 各編集はより新しいバージョン番号を伴う
→
III 行を再描画 触れた行だけを描き直す
→
IV 画面に表示 文字とカーソルが 1 フレームの何分の一かで見える
収束トラック · 背後で起きていること ハイライトと組版が、あなたを妨げることなく追いつく

3 つの独立したパイプライン

数式、図表、テーブルはそれぞれ独立に計算されます。 LaTeX の数式は入力の手が止まるまで待ち、Mermaid の図は見えている範囲だけを描画し、テーブルは自身の列幅を測ります。文章を編集しても、高コストな図の再計算は発生しません。

数式スナップショット Mermaid ビューポートキャッシュ 適応型テーブル

テキストとグラフィックスを分離

処理を分けることで、どちらも相手を待つことがありません。 テキスト編集、カーソルのヒットテスト、インクリメンタル再解析、統計処理はプロセッサ上で行われ、グリフ描画、レイヤー合成、ベクター描画はグラフィックスカード上で行われます。

テキストエンジン グリフシェイピングキャッシュ GPU ハードウェアアクセラレーション

強靭なクラッシュ復旧

突然の電源断からあなたの思考を守ります。 内蔵のタイムマシンが最大 100 件の履歴スナップショットを保持し、オフラインでの差分確認に対応します。さらに軽量な復旧ジャーナルが、再起動と同時に未保存の作業を復元します。
