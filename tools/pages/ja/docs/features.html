第 3 章

使い方 & 機能ガイド

Akileas の全体像を一通りご案内します。その場で編集する編集モデル、マルチビューポートでの執筆、アウトラインによるナビゲーションと検索、Git 不要のローカルタイムマシン、ネイティブな LaTeX と Mermaid のレンダリング、AI Agent ワークベンチ、出版品質の Typst PDF 書き出し、そしてすべてのキーボードショートカットです。

3.1 その場で編集するハイブリッド WYSIWYG

従来の Markdown エディターは、大きく二つの方式に分かれます。左側でソースを書き、右側でプレビューを確認する、分断された固定的な 2 ペイン方式。あるいは、基盤となる構文を容易に壊してしまうリッチテキスト表示方式です。Akileas は、その場で編集するハイブリッド WYSIWYG というアプローチを採用しています。

  • 編集時はソースを表示します。カーソルが段落、数式、表、見出しのブロックに入ると、そのブロックはただちに明快な Markdown ソース構文へと展開され、細部まで正確に調整できます。
  • 離れるとレイアウトを描画します。カーソルがブロックから離れると、内容はその場で美しいベクター組版として描画されます。見出しは太さと大きさを増し、数式は印刷品質の数学的表記になり、表は自動で調整されるグリッドになり、コードブロックには構文ハイライトが適用されます。
  • 構文を壊しません。保存される内容は常にクリーンで素朴な Markdown テキストです。冗長で乱れた非推奨の HTML タグが混入することは一切ありません。

3.2 複数ドキュメントの分割ビュー

文献の比較、章ごとに進める長編の執筆、参照の多い作業のために、Akileas はネイティブな分割画面を備えています。

  • 右に分割。現在のビューポートを左右 2 つに分割します（ショートカットはメニューから実行できます）。それぞれが独立してスクロールします。
  • 下に分割。2 つのビューポートを上下に配置し、縦方向の比較を行えます。
  • 同一ドキュメントの双方向ライブ同期。両方のビューポートで同じドキュメントを開いている場合、内容は 1 つのコピーを共有します。左側のビューポートで入力すると、右側の描画中のビューポートがミリ秒単位の遅延で更新され、それぞれのスクロール位置とカーソル選択は完全に独立して保たれます。
  • シームレスなフォーカス移動。Ctrl + H / J / K / L を押すと、Vim と同じように滑らかに分割ビューポート間でフォーカスを移動できます。

3.3 アウトラインによるナビゲーション & 検索システム

フローティングのアウトラインナビゲーションツリー

フローティングのドキュメントアウトラインツリー（Cmd + D / Ctrl + D）は、現在のドキュメント内の H1 から H6 までのすべての見出しを自動的に抽出し、インデントされたツリー階層として表示します。ノードをクリックすると該当するセクションへ滑らかにジャンプし、スクロールに合わせて、いま読んでいる位置を含む見出しノードが自動的にハイライトされます。

インラインの検索と置換

インラインの検索と置換（Cmd + F / Ctrl + F、Cmd + H / Ctrl + H）は、プレーンテキスト検索、単語単位の一致、大文字と小文字の区別に加えて、強力で非常に高速な Regex 一致モードをサポートします。一致した箇所は半透明の金色のハイライトとしてビューポート上に重ねて表示され、Enter / Shift + Enter で前後へすばやく移動できます。

ワークスペース全体とファイル単位のアクセス

  • ワークスペース全体の検索（Cmd + B / Ctrl + B）は、現在開いているフォルダー配下のすべての Markdown ドキュメントを即座に走査し、ファイル名またはテキストの断片による高速なあいまい検索を行えます。
  • クイックエクスプローラー（Cmd + E / Ctrl + E）は、サイドのファイルディレクトリツリーを手軽に呼び出し、ワークスペースの構成を軽快かつ効率的に管理できます。

3.4 Git 不要のローカルタイムマシン

多くのユーザーは Git を設定していないプロジェクトディレクトリで作業しており、誤ってテキストを削除したり、ファイルを破損させたり、内容を上書きしたりするリスクがあります。Akileas には、導入するだけでそのまま使えるタイムマシンが組み込まれています。

  • タイムマシンパネルを呼び出します。Cmd + Shift + H（macOS）または Ctrl + Shift + H（Windows/Linux）を押します。
  • 依存関係なしで独立して動作します。現在のファイルが Git リポジトリ内にあるかどうかに関わらず、Akileas は独自の専用履歴データベースを維持し、最大 100 件のスナップショットを巡回的に保存します。
  • 文字単位の差分表示。タイムマシンの画面では、異なる履歴バージョン間の文字単位の追加と削除を表示します（追加は緑、削除は赤、対応する行番号付き）。外部ツールは必要ありません。
  • 秒単位のチェックアウトと復元。履歴一覧でバージョンをクリックするとその時点の状態をプレビューでき、続けて Restore をクリックすれば安全に巻き戻せます。

また、Cmd + Shift + S / Ctrl + Shift + S を使えば、いつでも手動でマイルストーンのスナップショットを作成できます。

3.5 ネイティブな LaTeX と Mermaid 図

外部プラグインもネットワーク接続も必要ありません。Akileas はプロ品質の組版要素をネイティブに描画します。

LaTeX 数式

インライン数式は $E = mc^2$ のように記述し、テキストの流れの中に美しく組版されます。ブロックレベルの表示数式は $$ ... $$ を使用し、複雑な積分、行列、微積分、連立方程式をサポートします。19 種類の数学用ベクターフォントを内蔵しており、美しく鮮明な字形を実現します。

モダンな Mermaid ベクター図

  • フローチャート（graph TD）、シーケンス図（sequenceDiagram）、状態図、クラス図、マインドマップをサポートします。
  • シーケンス図の box グループ化コンテナ（例：box rgb(240, 248, 255) business module ... end）や複数行ラベル（<br> または <br/>）など、モダンな Mermaid 構文を完全にサポートします。
  • 動的な操作とローカル拡大鏡。マウスホイールによる滑らかなズームと、押したままドラッグするパン操作に対応し、図を縮小すると 360x240 のローカルシェーディング付き拡大鏡が自動的に有効になるため、複雑なアーキテクチャ図の細部まで鮮明に読み取れます。

3.6 AI Agent 設定ワークベンチ

SKILL.md や AGENTS.md を扱う次世代の開発者と AI Agent アーキテクトのために作られた専用ツールです。

  • 仕様の自動認識。SKILL.md、AGENTS.md、または .github/copilot-instructions.md を開くと、エディターは専用の Agent 拡張モードへ自動的に切り替わります。
  • 無損失の行単位字句解析。64KB / 512 行という安全な範囲内で frontmatter メタデータをすばやく走査しつつ、ユーザーの元のフィールド順序とコメント書式を厳密に保持します。
  • フローティングの問題診断パネル。必須フィールドの欠落（name、description、version など）を自動検出し、ディレクトリ名と識別子が Skill 仕様に適合しているかを検証し、セマンティックバージョニング（SemVer）形式を厳密に検証します。
  • ワンクリックのクイック修正。診断結果の中の修正ボタンをクリックすると、仕様テンプレートと不足しているフィールドがただちにドキュメントへ適用されます。

3.7 出版品質の Typst PDF 書き出し

ブラウザー経由で PDF を印刷したときに生じるぼやけやレイアウトの崩れとはお別れです。Akileas はモダンな組版エンジンである Typst を内蔵し、ベクタードキュメントを直接書き出します。

  • 書き出しを実行します。メニューの File -> Export as PDF… をクリックします。
  • プロ仕様の書き出しパラメーター。国際標準のページサイズ A4 または US Letter、縦向きまたは横向きの向き、5mm から 60mm まで精密に設定できるカスタム余白、そしてヘッダー、フッター、動的なページ番号を印刷するかどうかを自由に選べるページ番号とヘッダーの設定を備えています。
  • 真のベクター埋め込み。Markdown のテキスト、数式、Mermaid のトポロジー図はすべて高精度のベクターメタデータに変換されて PDF に埋め込まれ、1 万倍に拡大しても完全に滑らかで鮮明なまま、学術誌や出版物に匹敵する印刷品質を実現します。
