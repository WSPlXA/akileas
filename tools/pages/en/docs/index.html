Manual

The Akileas Manual

Four chapters: measured performance, why the editor is so fast, the complete feature and shortcut reference, and a tour of the eight core screens. Start wherever your question is.

What this manual covers

Akileas is a native Markdown editor built for uncompromising responsiveness. It renders maths and diagrams natively, edits in place as a hybrid of source and typeset view, and exports publication-grade vector PDF. Every document stays on your own disk.

Whether you are writing a thousand-line note or a hundred-thousand-line manuscript, the response stays sub-millisecond. The four chapters below answer, in turn: how it measures up, why it can be this fast, how each feature is used, and what each screen looks like.

  1. Chapter I Performance & Benchmarks Microsecond-scale response, parse latency at ten and a hundred thousand lines, large-document search speed, memory footprint, and the full editor comparison.
  2. Chapter II Why Akileas Is So Fast What happens between a keystroke and the repainted screen: instant response with background refinement, recomputing only what changed, three independent render pipelines, instant navigation in huge documents, and storage that survives a crash.
  3. Chapter III Usage & Feature Guide In-place hybrid WYSIWYG, split views, the outline and search system, the Git-free time machine, maths and diagrams, the Agent configuration workbench, and PDF export.
  4. Chapter IV Interface Tour The eight core screens, one by one: what each one does, how to open it, and what you will see.

How to read this manual

The four chapters stand alone, so you can jump straight to whatever you need.

See how fast it is

Go to the measurement tables and the comparison matrix in Chapter I. Every figure comes from a real release build on the machine recorded in that chapter.

Understand where the speed comes from

Chapter II walks through the whole path from key press to repainted screen, with diagrams and no technical background required.

Start using it

Chapter III covers every capability and how to reach it. The shortcut reference at the end works as a day-to-day cheat sheet.

Look at the interface first

Chapter IV tours eight screens covering the typical ways people use Akileas, each with its opening shortcut or menu path.

The performance figures in Chapter I were measured on the reference machine recorded in that chapter. Absolute numbers will differ on other hardware; the order of magnitude and the relative advantage do not.
