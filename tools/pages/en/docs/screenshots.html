Chapter IV

Screenshot Guide

A repeatable recipe for producing the eight canonical Akileas interface screenshots: one capture environment, one shared demo document, and eight precisely staged scenes.

4.1 Capture Conventions

Recommended operating system environments: Windows 11 (with dark mode enabled) or macOS Sonoma / Sequoia (with dark mode enabled).

Recommended uniform screenshot resolutions: 1920 × 1080 or 1440 × 900 for full-screen or large-window interfaces; 800 × 600, or the 16:10 golden ratio, for close-ups of local dialogs and panels.

For the appearance theme, use Akileas’ default refined dark theme (Dark Mode), which better highlights syntax highlighting and the premium feel of vector diagrams.

Screenshots must be saved uniformly as 24-bit PNG (lossless compression) to keep fine license and credential details crisp along with the smooth edges of type. Store screenshots in the assets/screenshots/ directory.

TIP

Capture every scene in the same theme and at the suggested window size so the resulting set reads as one coherent product tour rather than eight unrelated windows.

4.3 The Eight Canonical Scenes

Each scene below lists its target storage path, the points it must demonstrate, the preparation steps, the recommended window size, and the caption to use.

Scene 1: Main Editing Workbench, Full View (Immersive Typesetting and Hybrid WYSIWYG)

Focus: Show the minimal, distraction-free main editor window: the immersive title-bar-free design, beautifully rendered H1/H2 headings, highlighted blockquote borders, and checkbox components. Target storage path: assets/screenshots/01_main_editor_view.png.

  1. Open the demo_showcase.md file described above.
  2. Place the cursor inside an ordinary body paragraph (do not select any block, so that pure typesetting is shown).
  3. Make sure the window is centered, presenting a clean, restrained visual design.

Recommended window size: 1440 × 900.

Scene 2: Multi-Viewport Bidirectional Real-Time Split View

Focus: Show the same document presented in two viewports under a horizontal split (Split Right). The left side stays in Markdown source editing state (for example, while a table or list is being edited) while the right side renders the typeset result in real time, directly demonstrating “millisecond-generation synchronization across multiple viewports of one source”. Target storage path: assets/screenshots/02_split_screen_editing.png.

  1. Click the menu Document -> Split Right (or press the keyboard shortcut).
  2. In the left viewport, click a paragraph so it is in source input state (cursor blinking).
  3. Keep the right viewport in reading/rendered state; scroll down slightly to show a different section.

Recommended window size: 1600 × 900.

Scene 3: Modern Complex Mermaid Vector Architecture Diagram (with box Containers and Line Breaks) and the Local Magnifier

Focus: Show a complex Mermaid sequence diagram compiled purely in Rust, emphasizing the supported modern syntax features: box color grouping containers, <br> line breaks, and the hover interaction viewport (a zoom-factor readout or the local magnifier Lens mode). Target storage path: assets/screenshots/03_mermaid_diagram_lens.png.

  1. Scroll to the Mermaid sequence diagram region of demo_showcase.md.
  2. Use the mouse wheel to fine-tune the zoom level (for example, zoom to 75% to summon the detail magnifier, or center the clear topology arrows and text).
  3. Make sure the translucent light-blue box background blocks and the participant lifelines in the sequence diagram are crisp and attractive.

Recommended window size: 1200 × 750.

Scene 4: Ratex High-Fidelity LaTeX Complex Math Typesetting

Focus: Show Knuth box-model mathematical formulas solved by the pure-Rust Ratex engine, demonstrating the Einstein gravitational field tensor equation and the vector smoothness of complex sub/superscripts, radicals, and fraction bars. Target storage path: assets/screenshots/04_latex_math_typesetting.png.

  1. Locate the document region containing the two block-level LaTeX formulas.
  2. Capture a close-up of either the formula region or the main editor window with the formulas centered and their glyph outlines sharply defined.
  3. Optionally show a paragraph above the formulas containing the inline formula $E=mc^2$ as a comparison.

Recommended window size: 1000 × 600.

Scene 5: The Git-Independent Local Version Time Machine and Myers Diff Comparison

Focus: Show the Time Machine panel. The left side is the scrolling timeline history list, and the right side is the character-level Myers Diff comparison view (prominent green inserted lines and red deleted lines), conveying extreme reliability with no Git dependency. Target storage path: assets/screenshots/05_time_machine_diff.png.

  1. Make two small edits to the document and press Cmd+S / Ctrl+S to save each one, producing two history snapshots.
  2. Press Cmd+Shift+H (macOS) or Ctrl+Shift+H (Windows/Linux) to open the Time Machine dialog.
  3. Select the previous version so that the right side clearly shows the red/green diff comparison.

Recommended window size: 1280 × 800.

Scene 6: Document Hierarchy Outline Tree and Global Quick Search

Focus: Show the floating document outline (an H1–H6 tree structure) summoned with Cmd+D / Ctrl+D, or the inline highlighted search box summoned with Cmd+F / Ctrl+F, highlighting the precise navigation experience. Target storage path: assets/screenshots/06_outline_and_search.png.

  1. In a long document, press Cmd+D (on Windows, Ctrl+D) to expand the side or floating outline view.
  2. Summon the find overlay at the same time or separately (enter a keyword such as Authority so that multiple matches in the viewport are highlighted in gold).
  3. Capture the interface state showing the outline highlight anchors together with the search input box.

Recommended window size: 1440 × 900.

Scene 7: The AI Agent Specification Workbench and the Problems Diagnostic Repair Panel

Focus: Show the dedicated agent-configuration experience that appears when a SKILL.md or AGENTS.md file is opened. A specification diagnostics Problems panel floats at the bottom of the interface, marking missing fields and offering a “Quick Fix” one-click repair action. Target storage path: assets/screenshots/07_agent_workbench_problems.png.

  1. Create or open a SKILL.md file and deliberately omit the version field — for example frontmatter containing name: sample-agent-skill and description: 用于自动化测试的智能体技能配置, with the body # 技能正文.
  2. Check the status bar or trigger the overlay to bring up the stutter-free diagnostics panel, which occupies only 8 lines.
  3. Capture the detail showing the yellow warning / red error lines together with the “fill in required fields” button.

Recommended window size: 1280 × 750.

Scene 8: Publication-Grade Typst Vector PDF Export and High-Fidelity Print Preview

Focus: Show the export configuration dialog that opens from File -> Export as PDF… (A4 paper, margin fine-tuning, vector options) alongside the final exported high-resolution PDF page, conveying a journal-grade quality of layout. Target storage path: assets/screenshots/08_typst_pdf_export.png.

  1. Click the menu File -> Export as PDF… to open the export configuration dialog.
  2. Export the generated demo_showcase.pdf and open its first page in a PDF reader.
  3. Capture the export configuration dialog, or arrange the editor and the exported PDF side by side.

Recommended window size: 1440 × 900.
