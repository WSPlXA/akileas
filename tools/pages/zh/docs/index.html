使用手册

Akileas 使用手册

全书共三章：实测性能数据、快速的原因、完整功能与快捷键。 无论你是想快速上手，还是想先弄清它到底快在哪里， 都可以直接从对应的章节读起。

本手册涵盖的内容

Akileas 是一款原生 Markdown 编辑器，为毫不妥协的响应速度而打造。 它内置数学公式与图表渲染，支持就地混合所见即所得，并能导出出版级矢量 PDF。 所有文档只保存在你的本地磁盘上。

无论是在一千行的日常笔记中，还是在十万行的工程长文里，交互响应都保持在亚毫秒级别。 下面三章分别回答：它的实测表现如何、为什么能做到这么快， 以及每一项功能怎么用。

  1. 第一章 性能测评与基准实测 微秒级即时响应、一万行与十万行文档的解析耗时、超大文档检索速度、 内存占用对比，以及完整的编辑器横向对比矩阵。
  2. 第二章 为什么 Akileas 这么快 击键到画面刷新之间发生了什么：即时响应与后台精修的双阶段渲染、 只重算改动的那一部分、三条互不拖累的渲染管线、十万行瞬时定位， 以及崩溃断电也不丢稿的存储设计。
  3. 第三章 产品用法与功能全景 就地混合所见即所得、多视口分屏、大纲与检索体系、免 Git 本地时光机、 数学公式与图表、Agent 配置工作台，以及 PDF 导出。

怎么读这本手册

三章内容彼此独立，可以按需要直接跳读。

想先看它有多快

直接读第一章的实测数据表与横向对比。所有数字都来自同一台真实机器上的正式发行版本。

想了解快在哪里

第二章用图示解释了从按键到画面刷新的整个过程，不需要任何技术背景。

准备开始使用

第三章覆盖全部功能与操作方式，章末的快捷键速查表可以直接当作日常参考。

第一章的性能数字测量自该章所记录的参考机器。不同硬件上的绝对值会有所差异， 但量级与相对优势是一致的。
