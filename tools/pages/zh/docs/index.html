技术文档

Akileas 技术手册

全书共四章，分别覆盖真实性能实测数据、编辑器底层系统架构、全部用户可用能力，以及界面截图的拍摄规范。 面向工程技术评审、产品演示与架构汇报场景编写。

本手册涵盖的内容

Akileas 是基于 Rust 2024 与 GPUI 打造的原生极速 Markdown 编辑器， 内置纯 Rust 的 LaTeX / Mermaid 渲染内核，并支持出版级的 Typst 矢量 PDF 导出。 它只坚守一条性能铁律：UI 线程永不等待。

无论是在一千行的日常笔记中，还是在十万行的工程长文里，交互物理响应均保持在亚毫秒级别。 以下四章分别记录这些指标如何被测量、系统如何被构建、日常使用中如何表现，以及界面如何被拍摄。

  1. 第一章 性能测评与基准实测 微秒级待定投影、一万行与十万行的权威解析延迟、SIMD 检索吞吐量、内存预算上限， 以及完整的编辑器横向对比矩阵。
  2. 第二章 技术栈与核心系统架构 Rust 2024 与 GPUI、异构 CPU/GPU 分工模型、双阶段热路径、基于 Rope 分块的零拷贝 Tree-sitter 解析，以及断电安全的存储体系。
  3. 第三章 产品用法与功能全景 就地混合所见即所得、多视口分屏、大纲与检索体系、免 Git 本地时光机、原生 LaTeX 与 Mermaid、Agent 工作台，以及 Typst PDF 导出。
  4. 第四章 界面实例与截图指引 截图环境与规范、统一体验演示样本文档，以及八大核心场景的逐张拍摄指引。

材料使用建议

四章内容均可独立引用。每一章都先给出它所要支撑的结论，再用实测数据、架构图或可复现命令加以佐证。

技术宣讲与架构汇报

重点引用第一章的微秒级基准数据表，以及第二章的异构计算分工图与双阶段热路径时序图。

用户手册与新人培训

第三章可独立作为上手指南使用，章末的快捷键速查表覆盖 macOS、Windows 与 Linux 全平台操作。

视觉材料与演示文稿
