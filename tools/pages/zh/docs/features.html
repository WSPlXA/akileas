第三章

产品用法与功能全景

从书写交互、多视口协作、检索导航，到公式图表、智能体配置与出版级导出， 本章完整介绍 Akileas 的每一项用户可用能力与对应操作方式。

3.1 就地混合所见即所得

传统 Markdown 编辑器要么是生硬的"左边写源码、右边看预览"割裂式双栏， 要么是容易破坏语法的富文本排版。Akileas 采用就地混合所见即所得交互模式。

  • 编辑即源码：当光标移入某一自然段、数学公式、表格或标题块时， 该块即刻以清晰的 Markdown 语法源码展开，方便精准微调。
  • 移开即排版：当光标移出该块后，内容瞬间在原地渲染为精美的矢量排版效果 （标题加粗缩放、公式直接转为印刷级数学式、表格转为自适应网格、代码块加上语法高亮）。
  • 零语法破坏：底层始终存储纯净的 Markdown 纯文本，绝不引入冗余无序的 HTML 废弃标签。

TIP

由于语法展开只发生在光标所在的那一块，长篇文档中不会出现满屏 `#` 与 `*` 的干扰， 阅读与写作共用同一块画布。

3.2 多文档多视口双向实时分屏

针对文献对比、长篇章节对照编写与资料参考场景，Akileas 提供原生分屏支持。

  • 水平拆分（Split Right）：将当前视口水平一分为二（快捷键可在菜单触发），左右独立滚动。
  • 垂直拆分（Split Down）：上下并列对比。
  • 同文档双向实时同步：左右视口同时打开同一篇文档时，它们在内存中 共享同一份 TextBuffer 引用。在左侧打字的同时， 右侧视口在微秒级别同步更新渲染，且各自保持完全独立的滚动距离与光标选区。
  • 无缝焦点穿梭：按下 Ctrl + H / J / K / L，即可在多个分屏视口间如同 Vim 般顺畅切换焦点。

3.3 悬浮大纲导航树与全向检索体系

悬浮文档大纲树

按下 Cmd + D（Windows / Linux 下为 Ctrl + D） 唤出大纲树：自动提取当前文档中的所有 H1 ~ H6 标题，以树状层级缩进展示， 支持点击一键平滑跳转到对应章节，并随滚动自动高亮当前阅读位置所属的标题节点。

内联查找与替换

Cmd + F / Ctrl + F 激活查找面板， Cmd + H / Ctrl + H 激活替换面板。支持：

  • 普通文本搜索、全字匹配（Whole Word）、大小写敏感（Match Case）。
  • 强大且极速的正则表达式模式（Regex Match）。
  • 命中结果在视口中以半透明金色高亮浮层展示，按 Enter / Shift + Enter 快速上下穿梭。

全局工作区检索与资源管理器

  • 全局检索（Cmd + B / Ctrl + B）： 瞬时扫描当前打开文件夹下的所有 Markdown 文档，支持按文件名或文本片段模糊搜索。
  • 快速资源管理器（Cmd + E / Ctrl + E）： 便捷在侧边唤出文件目录树，轻量高效管理工作区结构。

3.4 独立免 Git 的本地版本时光机

许多用户在未配置 Git 的项目目录中工作，面临误删文字、文件损坏或内容意外覆盖的风险。 Akileas 提供开箱即用的内置时光机。

  • 呼出时光机面板：按下 Cmd + Shift + H（macOS） 或 Ctrl + Shift + H（Windows / Linux）。
  • 无依赖独立运行：无论当前文件是否位于 Git 仓库中， Akileas 都会自动维护专属的历史版本数据库，滚动保留多达 100 份保存快照。
  • Myers Diff 离线对比：直观呈现不同历史版本之间的字符级增删差异 （绿色新增、红色删除、行号对应）。
  • 秒级检出与还原：点击版本历史记录即可快速预览历史状态， 点击"还原此版本（Restore）"即可安全回退。
  • 里程碑快照：随时通过 Cmd + Shift + S / Ctrl + Shift + S 手动创建版本锚点。

3.5 纯原生 LaTeX 数学公式与现代 Mermaid 矢量图表

无需任何外部插件或联网，Akileas 原生渲染专业排版组件。

LaTeX 数学公式

  • 行内公式：使用 $E = mc^2$，在文字流中优雅排版。
  • 块级展示公式：使用 $$ ... $$，支持复杂积分、矩阵、微积分、方程组等。 19 套 KaTeX 矢量字体轮廓深度内置，字形优美清晰。

现代 Mermaid 矢量图表

  • 支持流程图（graph TD）、时序图（sequenceDiagram）、状态图、类图、思维导图。
  • 完整支持现代 Mermaid 语法：包括时序图中的 box 分组容器 （例如 box rgb(240, 248, 255) 业务模块 ... end）以及多行换行标签 （<br> 或 <br/>）。
  • 动态交互与局部放大镜：支持鼠标滚轮平滑缩放与按住拖拽平移。 当图表缩小时，自动激活 360x240 局部着色器放大镜，让复杂架构图细节纤毫毕现。

3.6 AI Agent 配置专属工作台

作为面向下一代开发者与 AI Agent 架构师的利器，Akileas 原生内建智能体配置规范工作台。

  • 自动规范识别：当打开 SKILL.md、AGENTS.md 或 .github/copilot-instructions.md 时，编辑器自动切换到专属 Agent 增强工作模式。
  • 无损行级词法分析：在 64KB / 512 行安全边界内快速扫描 Frontmatter 元数据， 严格保留用户的原始字段排布与注释格式。
  • 悬浮 Problems 诊断面板：自动检测必填字段缺漏（如 name、 description、version 等）；校验 Skill 规范中的目录名称与标识符匹配； 严格校验语义化版本号（SemVer）格式。
  • Quick Fix 一键补全修复：点击诊断提示中的修复按钮， 即刻自动将规范模板与缺漏字段打补丁注入文档。

3.7 出版级 Typst 矢量 PDF 导出

告别无头浏览器（Headless Chrome）导出 PDF 产生的模糊与排版错乱。 Akileas 内置了由 Rust 编写的现代化排版引擎 Typst 0.15。

  • 触发导出：点击菜单 File -> Export as PDF…。
  • 专业导出参数配置：页面尺寸支持国际标准 A4 或 US Letter； 版面方向支持纵向（Portrait）或横向（Landscape）；边距可从 5mm 到 60mm 精确设定； 页眉、页脚及动态页码可自由选择是否打印。
  • 真矢量嵌入：Markdown 文本、数学公式与 Mermaid 拓扑图均转换为高精矢量元数据嵌入 PDF， 放大万倍依然绝对平滑清晰，达到学术期刊与出版物级的打印品质。
