第四章

界面实例与截图指引

为制作最具说服力、视觉冲击力与专业度的宣传材料与技术 UI 演示文档， 本章提供八大核心场景的详尽截图拍摄指引，每个场景均配备目标路径、演示重点、 可一键复制的样例代码与推荐窗口尺寸。

4.1 截图规范与环境建议

  • 建议操作系统环境：Windows 11（启用深色模式） 或 macOS Sonoma / Sequoia（启用深色模式）。
  • 推荐统一截图分辨率：全屏 / 大窗口界面 1920 × 1080 或 1440 × 900；局部弹窗 / 面板特写 800 × 600， 或保持 16:10 黄金比例。
  • 外观主题选择：推荐使用 Akileas 默认的深色精致主题（Dark Mode）， 更能突出语法高亮与矢量图表的高级质感。
  • 截图格式要求：统一采用 24-bit PNG 格式（无损压缩）， 确保证照细节与字体平滑边缘清晰。
  • 存放位置：全部截图建议存放于 assets/screenshots/ 目录下。

4.2 统一体验演示样本文档

在拍摄截图前，建议在 Akileas 中新建一份名为 demo_showcase.md 的文件， 并将以下综合测试代码完整粘贴进去，即可一次性获得所有精美排版效果。 

# Akileas: 纯 Rust 原生极速 Markdown 编辑体验

> **UI 线程永不等待**：微秒级双阶段投影，十万行巨型文档丝滑交互。

## 1. 核心架构与时序协作

```mermaid
sequenceDiagram
    autonumber

    participant UI as EditorView
    participant GPUI as GPU Pipeline

    end

```

爱因斯坦场方程与高斯正态分布密度函数：

$$
R_{\mu\nu} - \frac{1}{2}R g_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}
$$

$$f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}$$

4.3 八大核心场景拍摄指引

场景 1：主编辑工作台全景（沉浸式排版与混合所见即所得）

展示极简无干扰的现代编辑器主窗口、无标题栏沉浸设计、精美的一级 / 二级标题渲染、 引用块边框高亮以及勾选框组件。

  1. 打开上述 demo_showcase.md。
  2. 将光标放置于普通的正文自然段内（不要选中任何块，以便展示纯排版效果）。
  3. 确保窗口居中，呈现出干净、克制的视觉设计。

推荐窗口尺寸：1440 × 900

场景 2：多视口双向实时分屏协作（Split View）

展示同文档在水平分屏（Split Right）下的双视口呈现。左侧处于 Markdown 源码编辑状态 （如正在编辑一个表格或列表），右侧实时同步呈现排版后状态， 直观体现"同源多视口毫秒级代际同步"。

  1. 点击菜单 Document -> Split Right（或按快捷键）。
  2. 在左侧视口中点击某一段落使其处于源码输入状态（光标闪烁）。
  3. 右侧视口保持阅读渲染状态，可轻微向下滚动展示不同章节。

推荐窗口尺寸：1600 × 900

场景 3：现代复杂 Mermaid 矢量架构图（含 box 容器与换行）与局部放大镜

展示纯 Rust 编译的复杂 Mermaid 时序图，重点突出支持的现代语法特性—— box 色彩分组容器、<br> 换行以及悬浮交互视口 （缩放倍率展示或局部放大镜 Lens 模式）。

  1. 滚动至 demo_showcase.md 中的 Mermaid 时序图区域。
  2. 使用鼠标滚轮微调缩放比例（例如缩放到 75% 唤出细节放大镜， 或居中展示清晰的拓扑箭头与文本）。
  3. 确保时序图中的 box 浅蓝透明背景块和 participant 生命线清晰美观。

推荐窗口尺寸：1200 × 750

场景 4：Ratex 高保真 LaTeX 复杂数学公式排版

展示纯 Rust Ratex 引擎求解的 Knuth 盒模型数学公式， 展现爱因斯坦引力场张量公式与复杂的上下标、根号、分数线矢量平滑度。

  1. 定位到包含两个 LaTeX 块级公式的文档区域。
  2. 截取公式居中、字形轮廓分明的局部或主编辑窗口特写。
  3. 可以在公式上方展示一行带行内公式 $E=mc^2$ 的段落作为对比。

推荐窗口尺寸：1000 × 600

场景 5：独立于 Git 的本地版本时光机与 Myers Diff 差异比对

展示时光机（Time Machine）面板。左侧为时间线滚动历史记录列表， 右侧为字符级 Myers Diff 差异对比视图（醒目的绿色增量行与红色删除行标记）， 体现无 Git 依赖下的极端可靠性。

  1. 对文档做两处小修改并分别按 Cmd + S / Ctrl + S 保存两次，产生历史快照。
  2. 按下快捷键 Cmd + Shift + H（macOS）或 Ctrl + Shift + H（Windows / Linux）唤出时光机弹窗。
  3. 选中前一个版本，使右侧清晰展现红绿对比的差异 Diff。

推荐窗口尺寸：1280 × 800

场景 6：文档层级大纲导航树与全局快速检索

展示按 Cmd + D / Ctrl + D 呼出的悬浮文档大纲 （H1~H6 树形结构），或者按 Cmd + F / Ctrl + F 唤出的内联高亮检索框，凸显精准导航体验。

  1. 在长文档中按下 Cmd + D（Windows 下按 Ctrl + D） 展开侧边或悬浮大纲视图。
  2. 同时或者单独唤出查找浮层（输入关键词如 Authority， 视口中多处匹配字符呈现高亮金光）。
  3. 截取带有大纲高亮锚点与检索输入框的界面状态。

推荐窗口尺寸：1440 × 900

场景 7：AI Agent 规范工作台与 Problems 诊断修复面板

展示打开 SKILL.md 或 AGENTS.md 时专属的智能体配置体验。 界面下方浮动展示规范诊断 Problems 面板，标出缺漏字段并提供 "Quick Fix" 一键修复动作。

  1. 新建或打开一个 SKILL.md 文件，故意缺漏 version 字段： frontmatter 仅含 name: sample-agent-skill 与 description: 用于自动化测试的智能体技能配置，正文为 # 技能正文。
  2. 查看状态栏或触发浮层，唤出仅占 8 行的无卡顿诊断面板。
  3. 截取显示黄色警告 / 红色错误行以及"补齐必填项"按钮的细节。

推荐窗口尺寸：1280 × 750

场景 8：出版级 Typst 矢量 PDF 导出与高保真打印预览

展示点击 File -> Export as PDF… 弹出的导出配置对话框 （A4 纸张、边距微调、矢量选项），以及并列展示最终导出的高分辨率 PDF 页面， 呈现期刊级的版面美感。

  1. 点击菜单 File -> Export as PDF…，弹出导出配置弹窗。
  2. 导出生成的 demo_showcase.pdf 并使用 PDF 阅读器打开第一页。
  3. 截取导出配置对话框或将编辑器与导出的 PDF 并列排布呈现。

推荐窗口尺寸：1440 × 900
