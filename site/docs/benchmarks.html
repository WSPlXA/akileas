Chapter 1

Performance & Benchmarks

Akileas holds to a single iron rule of performance: the UI thread never waits. Whether you are in a 1,000-line daily note or a 100,000-line architectural document, interaction stays at sub-millisecond speed. Every number below was measured from the official release build on the same real machine.

NOTE

Instant response is the time it takes for the character and the cursor to appear on screen after you press a key. Measured at 100,000 lines it takes only 37 microseconds (0.037 ms), less than one hundredth of a frame's budget, so the feel is identical to an empty document no matter how long the document is.

Background parsing is the time the editor needs to fill in syntax highlighting and fine typography behind the scenes. It never blocks your typing, and measures 0.703 ms at 100,000 lines.

Takeaways

  1. Everyday high-frequency typing stays extremely smooth: character entry, backspace deletion, inline bolding and cross-paragraph editing keep background parsing steady between 0.46 ms ~ 0.71 ms, while instant response takes only 38 microseconds.
  2. Structural changes never stutter either: when typing # triggers a heading block rewrite, the background has to recompute an entire block (about 997 ms); yet the screen has already updated within 85 microseconds, with no lag or dropped frames in keystroke and cursor feedback.

1.5 Memory Footprint and Cache Limits

Akileas has no runtime garbage collection, so it never suffers the periodic stutter of browser-engine editors. Its cold-start memory footprint compared with common editors is shown below.

Resident memory baseline: roughly 25 MB ~ 45 MB for light documents; a 100,000-line giant document stays steady at 60 MB ~ 110 MB and does not keep growing the longer you edit. Every cache has a defined ceiling and automatically evicts the least recently used content once it is exceeded:

  • Image cache: 64 MiB ceiling, at most 256 images, and no more than 8 concurrent decodes; abnormally large images are rejected to prevent memory exhaustion.
  • Diagram geometry cache: 32 MiB ceiling. Zooming and panning only adjust coordinates; shapes are never recomputed.
  • Formula typesetting cache: 32 MiB ceiling, with 19 built-in mathematical vector fonts.
  • Configuration file analysis: scans only a short stretch at the very beginning, and directory traversal automatically skips build artifacts and version-control directories.
