第四章

界面导览

从专注写作、分屏对照，到公式图表、版本回滚与出版级导出， 下面八个界面覆盖了 Akileas 的日常使用场景。每个界面都说明了它解决什么问题、 怎么打开，以及你会看到什么。

4.1 关于这些界面

Akileas 的界面刻意保持克制：没有多余的工具栏，没有反复切换的面板。 写作时它几乎隐入背景，需要某个能力时再用一个快捷键呼出，用完即走。

4.2 八大核心界面

主编辑界面

能做什么：这是你待得最久的地方。Markdown 语法只在光标所在的那一块展开， 移开之后立刻渲染成排版好的样子——标题、引用、代码块、勾选框都在原地变成最终形态。

你会看到：干净的深色版面，标题层级分明，引用块带一条柔和的边线， 任务列表显示为可点击的方框。没有左右分栏，也没有预览窗口。

分屏对照

能做什么：把同一个文档在左右两个视口里同时打开，一边改一边看整体效果； 也可以在两个视口里打开不同文档做资料对照。两边共享同一份内容， 在左侧输入，右侧会在毫秒级同步更新。

怎么打开：菜单 Document → Split Right（左右并排） 或 Split Down（上下并排）。用 Ctrl + H / J / K / L 在几个视口之间切换焦点。

你会看到：左右两个视口各自独立滚动、各自保留光标位置，但内容始终一致。

Mermaid 图表

能做什么：直接在文档里写流程图、时序图、状态图、类图与思维导图， Akileas 会把它渲染成矢量图形。支持分组容器与标签换行， 并可以用滚轮缩放、按住拖拽平移。

你会看到：图表以矢量方式绘制，放大后线条依然锐利； 图表被缩小时会自动出现一个局部放大镜，方便看清密集的节点与连线。

数学公式

能做什么：用 LaTeX 语法书写行内公式与块级公式， 支持积分、矩阵、方程组、上下标与根号等常见表达。

你会看到：公式以印刷级排版居中呈现，字形轮廓平滑， 放大后不会出现锯齿——包括希腊字母与各种数学符号。

版本时光机

能做什么：不用配置 Git，也能找回历史版本。 每次保存都会自动留下一份快照，最多保留 100 份； 你也可以用 Ctrl + Shift + S 手动打一个版本锚点。

怎么打开：按 Ctrl + Shift + H。

你会看到：左侧是版本时间线，右侧是选中版本与当前内容的逐字差异对比—— 绿色表示新增、红色表示删除，可以随时一键还原。

大纲与查找

能做什么：长文档里快速跳转与检索。 Ctrl + D 呼出大纲树，列出全部标题层级； Ctrl + F 查找、Ctrl + H 替换。

你会看到：大纲随滚动自动高亮当前所在章节，点击即可平滑跳转； 查找结果在正文中以高亮标出，按 Enter 在命中项之间穿行。 查找还支持全字匹配、区分大小写与正则表达式。

Agent 配置工作台

能做什么：写 SKILL.md、AGENTS.md 这类智能体配置文件时，Akileas 会自动切换到专用模式，检查开头的元数据是否完整： 必填字段有没有漏、名称是否匹配、版本号格式对不对。

你会看到：界面下方浮出一块轻量的诊断面板，逐条列出问题所在； 点击修复按钮即可自动补上缺失的字段或模板内容。

PDF 导出

能做什么：把文档导出成可以打印、可以投稿的 PDF。 正文、数学公式与图表都会以矢量形式嵌入，放大后依然清晰。

怎么打开：菜单 File → Export as PDF…。

你会看到：一个导出设置对话框，可以选择 A4 或 US Letter 纸张、 纵向或横向、页边距，以及是否打印页眉、页脚与页码。
