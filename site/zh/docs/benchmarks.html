第一章

性能测评与基准实测

Akileas 坚守唯一的性能铁律：UI 线程永不等待。无论是在 1,000 行的日常笔记中， 还是在 100,000 行的代码架构长文中，交互物理响应均保持在亚毫秒级别。

1.3 多编辑场景持久化压测

在实际日常写作中，编辑器 UI 会持续持有上一版本的语法树快照以复用节点。 以下为在本机保留快照（AKILEAS_BENCH_RETAIN=1）条件下， 针对 100,000 行巨型文档进行的多场景压力实测数据，每组模式 40 次样本循环。 

[Windows 11 / Intel Core 本机 100,000 行持久化语法树压力实测]
        ├─ 普通字符输入替换 (replace)  : Pending 0.038 ms │ Authority p50 = 0.716 ms │ p95 = 0.786 ms
        ├─ 交替插入/删除字符 (typing)   : Pending 0.038 ms │ Authority p50 = 0.712 ms │ p95 = 1.218 ms
        ├─ 行内强调语法变动 (syntax)   : Pending 0.038 ms │ Authority p50 = 0.716 ms │ p95 = 0.934 ms
        ├─ 多段落随机跳跃编辑 (distrib) : Pending 0.044 ms │ Authority p50 = 0.466 ms │ p95 = 0.626 ms
        └─ 标题结构性重构 (block)       : Pending 0.085 ms │ Authority p50 = 997.10 ms │ p95 = 1162.17 ms

本机评测核心结论

  1. 日常高频输入极度流畅：针对字符录入、退格删除、行内加粗高亮与跨段落编辑， 后台增量解析耗时稳定在 0.46 ms ~ 0.71 ms 之间，物理投影更是仅需 38 微秒。
  2. 结构性语法隔离保障：当输入 # 引起标题块语法重构时，解析器需遍历整块语法树 （耗时约 997 ms）；但由于 Stage 1 投影机制仅需 85 微秒， 用户击键与光标反馈绝无一丝卡顿与丢帧。

1.5 零 GC 内存开销与有界缓存预算

通过 Rust 所有权机制与 Microsoft mimalloc 全局分配器， Akileas 彻底消除了传统基于 Electron / Chromium 编辑器的垃圾回收（GC）丢帧停顿现象。 

pie title 常驻资源与缓存内存预算分布（总预算上限 150 MB）
            "基础运行与 Rope 文本缓冲" : 45
            "图片 LRU 缓存预算" : 64
            "Mermaid 矢量拓扑缓存" : 32
            "TeX 盒模型 DisplayList" : 32
  • 常驻内存基线：轻量文档仅需 25 MB ~ 45 MB； 十万行巨型文档稳定在 60 MB ~ 110 MB。
  • 图片缓存防护：严格限制上限 64 MiB、最大 256 个条目、 最大 8 个并发解码任务，超大异常图片拦截，杜绝 OOM。
  • Mermaid 矢量几何缓存：严格限制上限 32 MiB， 缓存 CPU 曲面细分与路径拓扑；平移时仅调整坐标矩阵，无需重新计算几何形状。
  • TeX 盒模型缓存：严格限制上限 32 MiB LRU 缓存， 预加载 19 套 KaTeX 矢量字体轮廓。
  • Agent 分析边界：前置安全围栏最多扫描前 64 KiB 或 512 行，最多保留 128 个顶层属性； 目录遍历跳过 build / target / .git，常驻索引文本最多 4 MiB。

1.7 性能测试复现指南

Akileas 包含全套可自动化复现的 Benchmark 源码。在项目根目录下通过 Cargo 即可执行真实压力测试。 

# 1. 编译压测套件（脱离网络与默认平台依赖）
        cargo bench --bench editor_latency --no-default-features --offline --no-run

        # 2. 执行默认 10,000 与 100,000 行标准基准测试
        cargo bench --bench editor_latency --no-default-features --offline

        # 3. 执行保留旧快照的持久化多模式测试（typing, syntax, distributed, block）
        for mode in typing syntax distributed block; do
          AKILEAS_BENCH_RETAIN=1 AKILEAS_BENCH_LINES=100000 AKILEAS_BENCH_SAMPLES=40 \
            AKILEAS_BENCH_MODE="$mode" cargo bench --bench editor_latency --no-default-features --offline
        done

TIP

第三组命令通过环境变量控制测试模式。若只关心日常输入热路径，运行 AKILEAS_BENCH_MODE=replace 即可跳过耗时的结构性重构场景。
