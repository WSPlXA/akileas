概览

核心承诺

文档留在本地所有 Markdown 文件与文件夹均直接在你的本地设备上读取、编辑与保存。
无需注册账号打开即可书写。没有注册、没有用户画像、没有身份追踪。
零遥测WSPlXA 不收集任何分析数据、文档内容、击键记录或使用历史。

一 · 本地处理

在你的设备上处理的信息

为实现响应式编辑、实时渲染、检索、持久化与崩溃恢复，Akileas 会在本地内存与存储中 直接处理你选择打开的文件与文件夹、粘贴的文本、当前会话历史，以及应用偏好设置。

偏好设置与有界崩溃恢复日志保存在你的本机。你可以随时通过操作系统的文件管理器 查看、备份或删除这些文件。

二 · 数据收集

WSPlXA 会收到什么

答案是什么都没有。Akileas 不会将你的文档内容、文件名、工作区结构、 剪贴板数据、偏好设置或使用分析传输给 WSPlXA。 我们不出售个人数据，也不与第三方广告网络共享任何信息。

三 · 网络访问

应用何时会连接网络

如果某份 Markdown 文档引用了以 http:// 或 https:// 开头的远程图片， Akileas 会向该主机请求资源以便内联渲染。该第三方服务器可能依据其自身的隐私政策， 记录标准的 HTTP 请求元数据，例如你的 IP 地址与 User-Agent。

当你在文档中点击外部链接时，目标地址由你的默认浏览器处理。 第三方网站依据其自身的隐私实践独立运营。

四 · 商店分发

Microsoft Store 数据

如果你通过 Microsoft Store 获取 Akileas，Microsoft 会依据 Microsoft 隐私声明 处理购买、安装、可靠性诊断与 Store 账户信息。 WSPlXA 不会通过 Microsoft Store 获取你的文档内容或本地文件。

五 · 未成年人

未成年人隐私

Akileas 是一款通用型生产力与技术写作应用。由于本应用不依赖云端账户， 也不进行远程数据收集，因此不会在知情情况下收集未成年人的个人信息。

六 · 变更

政策更新

若未来功能需要变更信息处理方式，本政策将被更新，并同步修订上方的生效日期。 重大更新将在官方发行说明中予以记录。
