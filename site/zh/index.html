设计理念

捷足的阿喀琉斯

在荷马的《伊利亚特》中，英雄阿喀琉斯被冠以「捷足」（πόδας ὠκὺς Ἀχιλλεύς）之名——象征着锐不可当的敏捷、毫无阻滞的冲势与纯粹的速度。在一个写作工具普遍被沉重的 Web 运行时与迟钝的 Electron 外壳拖慢的时代，Akileas 重新夺回那份毫不费力的迅捷：即时的击键响应、安静的简洁，以及一块绝不挡在你面前的画布。

σευάμενος ὥς θ᾽ ἵππος ἀεθλοφόρος σὺν ὄχεσφιν,
ὅς ῥά τε ῥεῖα θέῃσι τιταινόμενος πεδίοιο·
ὣς Ἀχιλεὺς λαιψηρὰ πόδας καὶ γούνατ᾽ ἐνώμα.

「如同一匹获奖的骏马拖着战车掠过平原，全力奔驰；
阿喀琉斯也这样迅捷地挥舞着他轻快的双脚与膝踝。」

—— 荷马《伊利亚特》第二十二卷（第 22–24 行）

连续交互画布

所写即所读。

Markdown 语法只在光标所在的那一行显现，一旦移开便立刻沉淀为精致的排版。没有双栏分割，没有思维上下文的切换——在单一画布上无缝衔接写作与阅读。

核心特性

为专注而设计，以精确为根基

轻到足以隐没在你的思绪之下，强到足以承载复杂的技术长文。

就地混合所见即所得

告别割裂的左右对照预览。原始 Markdown 语法只在光标所在的当前行展开，标题、列表、表格、链接与加粗文本就地实时渲染，让画布始终保持洁净。
